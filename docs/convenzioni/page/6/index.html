Criterio. Un’iniziativa è un ID Sigef Consip, o una gara (CIG padre) di un altro soggetto. È «attiva» se ha CIG derivati con CPV ICT nel 2024-2025 (o è nuova: PRINCO ID 2928, IaaS/PaaS 2 ID 2746). Le iniziative della base di conoscenza senza derivati recenti ma con almeno 100 M€ dal 2020 sono elencate a parte come «storiche». Dettagli: README della base dati.
