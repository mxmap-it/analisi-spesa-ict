Perché un mirror (bozza)

Bozza 0.1 del 6/11/2026, non elencata (#17). [V] = verificato da noi, con prova nel repository; [R] = riferito o dedotto, da verificare. Progetto tecnico: Mirror pubblico.

In breve

Una misura ripetibile ogni anno (l’obiettivo del progetto) richiede che i dati misurati restino disponibili e identici. Per le fonti principali oggi non è così: file rimossi senza regola, file fermi a mesi fa, finestre mobili che cancellano gli anni vecchi, mesi serviti con il contenuto di un altro mese. Nessuna delle fonti dichiara una politica di conservazione.

Che cosa aggiunge il mirror: le 1.796 risorse oggi disponibili, con sha256, data e intestazioni HTTP viste, conservate anche quando ANAC le sostituisce o le toglie; una via di accesso senza WAF; la prova riproducibile di ogni problema comunicato.

Che cosa non diciamo

Non diciamo che i dati siano «spariti per sempre» se non lo abbiamo misurato; per ANAC non conosciamo il motivo delle rimozioni. Le differenze fra versioni dello stesso URL non sono ancora misurabili sul nostro mirror: in 12 giorni nessuna risorsa ha cambiato sha256. Il confronto fra versioni diventerà una metrica quando ci saranno almeno due acquisizioni diverse.
